# AxisMacket: позиционирование оси на ESP32 + L293DD

Прошивка для ESP32, которая управляет мотор-редуктором **JGA25-370 (12 В, 130 об/мин)**
через драйвер **L293DD** (ESP-12E Motor Shield). Обратная связь идёт от встроенного двухканального (A/B) энкодера Холла.
Программа устроена так же, как проект оси в Automation Studio:

| Automation Studio / ACOPOS              | Здесь                                          |
|-----------------------------------------|------------------------------------------------|
| `gAxis` (ACP10AXIS_typ)                 | `Axis_typ gAxis` — [AxisTypes.h](ESP32_L293D_Axis/AxisTypes.h) |
| `Global.typ` / `Global.var`             | `AxisTypes.h` / глобальные переменные в `.ino` |
| `_INIT` / `_CYCLIC`, класс задач        | `ProgramInit()` / `ProgramCyclic()` в задаче FreeRTOS `Cyclic#1`, 5 мс |
| `gAxis.monitor.s`, `.v`                 | `gAxis.monitor.s`, `.v`, `.s_set`, `.v_set`, `.lag`, `.u` |
| `controller.position.kv`, `controller.speed.kv / tn` | те же поля, смысл тот же |
| `limit`, `ds_stop` (ошибка рассогласования) | `gAxis.limit.v`, `.a`, `.ds_stop`, окна |
| Встроенное ПО ACOPOS (профиль + каскад) | [Axis.cpp](ESP32_L293D_Axis/Axis.cpp) |
| `MC_MoveVelocity` (ACP10_MC)            | ФБ 1 — непрерывное движение, [MC_Move.cpp](ESP32_L293D_Axis/MC_Move.cpp) |
| `MC_MoveAbsolute` (ACP10_MC)            | ФБ 2 — перемещение в позицию по энкодеру |
| Watch-окно                              | консоль Serial, 115200 бод (`help`) |

Вызов ФБ записывается так же, как в C-программе AS:

```c
fbMoveAbsolute.Axis     = &gAxis;
fbMoveAbsolute.Position = 90.0f;     // градусы выходного вала
fbMoveAbsolute.Velocity = 360.0f;    // °/с
fbMoveAbsolute.Execute  = true;
MC_MoveAbsolute(&fbMoveAbsolute);    // каждый цикл
```

## 1. Характеристики двигателя и энкодера

Данные энкодера взяты со [схемы RoboticX](https://roboticx.ps/?attachment_id=20887).

| Параметр | Значение |
|---|---|
| Тип энкодера | инкрементальный, магнитный (датчики Холла), каналы A/B со сдвигом 90° |
| Питание энкодера | 3,3 В или 5 В (здесь **3,3 В**) |
| Импульсов на оборот вала двигателя | 11 PPR на канал (магнитное кольцо на 22 полюса) |
| Выход | меандр A/B, подтяжка на плате энкодера, до 100 кГц |
| Двигатель | 12 В, на выходе редуктора 130 об/мин без нагрузки |

**Цвета проводов (разъём PH2.0):**
красный — двигатель «+», белый — двигатель «−», синий — питание энкодера «+», чёрный — земля энкодера,
жёлтый — канал A, зелёный — канал B.

## 2. Расчёт передаточного числа и разрешения

Скорость двигателя 370 без нагрузки при 12 В: n_дв ≈ 6000–6100 об/мин.

```
i = n_дв / n_вых ≈ 6100 / 130 ≈ 46,9   →   стандартное передаточное число JGA25: 1 : 46,8
```

У соседних исполнений числа такие: 1:34 даёт около 170 об/мин, 1:78 — около 77 об/мин.
Встречаются и исполнения JGA25 с другим двигателем: например, у одного продавца 126 об/мин указано для 1:34.
Поэтому число 46,8 стоит подтвердить командой `cal` (см. п. 6). Она измеряет реальное i по энкодеру.

| Величина | Формула | Значение |
|---|---|---|
| Инкрементов на оборот вала двигателя (x4) | 11 × 4 | **44** |
| Инкрементов на оборот выходного вала | 44 × 46,8 | **2059,2** |
| Разрешение по выходному валу | 360 / 2059,2 | **0,175 °/инкр** |
| Частота одного канала при 130 об/мин | 130/60 × 11 × 46,8 | ≈ 1115 Гц |
| Прерываний в секунду (оба канала, оба фронта) | 1115 × 4 | ≈ 4460 /с — для ESP32 это немного |
| Номинальная скорость выходного вала | 130 × 6 | 780 °/с |
| Прямая связь по скорости `ff` | 12 В / 780 °/с | 0,0154 В/(°/с) |

На ключах L293D теряется примерно 1,5–2,5 В, поэтому до двигателя доходит около 10 В,
а максимальная скорость под нагрузкой составляет около 100–110 об/мин.
По этой причине `limit.v = 600 °/с` (100 об/мин).

## 3. Подключение

Драйвер — **ESP-12E Motor Shield** (L293DD), плата расширения под NodeMCU. Используется канал A.
Шилд управляется двумя сигналами: **PWMA** (ШИМ, скорость) и **DA** (направление).
Второй вход L293DD шилд формирует сам, инвертируя DA.
Удобнее всего подключаться к штырькам рядов **D1** (= PWMA) и **D3** (= DA).
Перед подключением прозвоните их с гнёздами PWMA/DA мультиметром.

На плате расширения ESP32 сигнал берётся с контакта **S** нужного ряда.
**V** — шина питания, **G** — земля.

| ESP32 (контакт S) | Куда |
|---|---|
| GPIO27 | шилд **PWMA** (штырёк D1) |
| GPIO32 | шилд **DA** (штырёк D3) |
| GPIO26 | энкодер, **жёлтый** (A) |
| GPIO25 | энкодер, **зелёный** (B) |
| V (перемычка на 3,3 В) или 3V3 | энкодер, **синий** (+) |
| G | энкодер, **чёрный** (−) и **G** шилда (общая земля) |

| Шилд | Куда |
|---|---|
| **VM** / GND (винтовые клеммы) | **+12 В** / «−» блока питания |
| Перемычка VM–VIN | **снята**, иначе 12 В попадут на штырьки V и Vin шилда |
| **A+** / **A−** | красный / белый провод двигателя |

| Направление | DA | PWMA |
|---|---|---|
| вперёд | 1 | ШИМ (скважность = скорость) |
| назад | 0 | ШИМ |
| стоп / ось выключена | — | 0 |

Если вместо шилда используется голая микросхема L293D, задайте в скетче `PIN_L293_IN2` номером GPIO.
Тогда прошивка будет управлять входами EN1 (ШИМ), IN1 и IN2 по отдельности.

> ⚠️ Энкодер питайте **от 3,3 В** с ESP32, а не со штырьков V или Vin шилда.
> Подтяжки стоят на плате энкодера и тянут выходы к его питанию, поэтому при 5 В на входы ESP32 попадёт 5 В.
>
> ⚠️ Неподключённые входы L293DD читаются как «1».
> Если подать 12 В на VM при отключённых PWMA/DA или до загрузки ESP32, двигатель поедет на полной скорости и драйвер перегреется.
> Поэтому подавайте 12 В **после** включения ESP32.
> Ещё лучше поставить резистор 10 кОм между PWMA и GND.
>
> ⚠️ L293DD рассчитан на 0,6 А длительно и 1,2 А в пике. Ток заторможенного JGA25-370 может быть выше.
> Ось отключается по ошибке рассогласования (`ds_stop`), но вал всё равно лучше не заклинивать надолго.

Входы L293DD воспринимают 3,3 В от ESP32 как логическую «1» (V_IH ≥ 2,3 В). Согласование уровней не нужно.

## 4. Структура прошивки

```
AxisMacket/
├── platformio.ini
├── README.md
└── ESP32_L293D_Axis/
    ├── ESP32_L293D_Axis.ino   ProgramInit/ProgramCyclic, задача 5 мс, консоль
    ├── AxisTypes.h            Axis_typ (gAxis), перечисления, коды ошибок
    ├── Axis.h / Axis.cpp      энкодер x4 на прерываниях, профиль, регулятор, ШИМ L293D
    └── MC_Move.h / .cpp       ФБ MC_MoveVelocity и MC_MoveAbsolute
```

**Цикл 5 мс (`ProgramCyclic`):** команды из консоли → вызовы ФБ → `Axis_Cyclic(&gAxis)`.

**Внутри `Axis_Cyclic` (каскад, как в ACOPOS):**

1. Энкодер: `s = (counts − offset) · units_per_count`. Скорость `v` равна разности позиций за цикл, пропущенной через фильтр 1-го порядка (`t_filter`).
2. Генератор профиля выдаёт `s_set`, `v_set`.
   В режиме скорости работает рампа с `acc`/`dec`.
   В режиме позиции строится трапеция: скорость ограничена величиной `√(2·dec·|остаток пути|)`, поэтому ось тормозит точно в цель.
   В коде используется дискретный вариант этой формулы для шага 5 мс. С непрерывной формулой задание перелетало бы цель примерно на 1°.
3. Контур положения: `v_cmd = v_set + kpos · (s_set − s)`.
   Если |рассогласование| больше `ds_stop`, выставляется ошибка 1002 и ось выключается.
4. Контур скорости (ПИ с прямой связью и защитой от насыщения интегратора): `u = ff·v_set + kv·(v_cmd − v) + I`, ограничение ±12 В.
5. Выход на драйвер: модуль `u` задаёт скважность ШИМ на PWMA (5 кГц, 10 бит), знак `u` задаёт уровень DA.
   Для голой L293D знак задаёт уровни IN1/IN2.

**ФБ 1 `MC_MoveVelocity`** (входы: Execute, Velocity, Direction, Acceleration, Deceleration;
выходы: InVelocity, Busy, Active, CommandAborted, Error, ErrorID)

- Фронт Execute запускает движение.
- Пока Execute = 1, новые Velocity и Direction применяются на ходу.
- Спад Execute плавно тормозит ось до остановки. В PLCopen для этого нужен MC_Stop, а здесь всего два ФБ, поэтому торможение встроено в спад.

**ФБ 2 `MC_MoveAbsolute`** (входы: Execute, Position, Velocity, Acceleration, Deceleration;
выходы: Done, Busy, Active, CommandAborted, Error, ErrorID)

- Фронт Execute запускает перемещение.
- Done выставляется, когда генератор дошёл до цели и фактическая позиция попала в окно `in_pos_window` (1°).

Оба ФБ прерывают друг друга. Новая команда увеличивает `gAxis.move.cmd_id`, и прерванный блок выставляет `CommandAborted`.

**Защиты:**

- Консоль принимает только конечные числа. Строки `nan`, `inf`, `12abc` отклоняются: NaN проскочил бы мимо проверки рассогласования.
- Параметры проверяются на допустимый диапазон.
- `set motdir`, `encdir`, `ratio`, `ppr` работают только при выключенной оси. Смена направления на ходу превращает обратную связь в положительную.
- Если у оси ненулевая скорость, а пришла `ma` к близкой точке, ось не останавливается мгновенно. Она проезжает цель и возвращается по профилю.
- Дополнительно ось отключается при любом нечисловом значении в регуляторе.

**Коды ошибок:**

| Код | Значение |
|---|---|
| 1000 | не задан Axis |
| 1001 | ось не включена |
| 1002 | превышено рассогласование |
| 1003 | неверный параметр |
| 1004 | ось в ошибке |
| 1005 | операция разрешена только в покое |

## 5. Сборка и прошивка

- **Arduino IDE:** установите плату «ESP32 by Espressif» (ядро 2.x или 3.x, оба поддерживаются),
  выберите *ESP32 Dev Module* и откройте `ESP32_L293D_Axis/ESP32_L293D_Axis.ino`.
  Тулчейн ESP32 под Windows иногда не собирает проект из пути с кириллицей.
  Если сборка падает, скопируйте папку скетча в путь без кириллицы, например `C:\esp\ESP32_L293D_Axis`.
- **PlatformIO:** откройте папку `Индивидуальное задание`, выполните `pio run -t upload`, затем `pio device monitor`.

## 6. Первый запуск (порядок проверки)

1. Подключите монитор порта на 115200 бод. Команда `par` выводит параметры.
2. **Направление энкодера.** Пока ось выключена, поверните выходной вал рукой и посмотрите в `st`, растёт ли `counts`.
3. **Калибровка передаточного числа.**
   - Введите `cal` и отметьте положение вала.
   - Поверните вал рукой ровно на N оборотов (например, 5) и введите `cal 5`.
   - Прошивка выведет реальное `i`. Запишите его в `GEAR_RATIO` в скетче.
4. Введите `on`, затем `mv 60`: вал должен медленно поехать.
   Если сразу возникает «ОСЬ: ошибка 1002», направления двигателя и энкодера не совпадают.
   Выполните `reset` и `set encdir -1`, либо поменяйте местами жёлтый и зелёный провода.
5. Проверка ФБ 1: `mv 300`, `mv -300`, `rpm 50`, `stop`. Должны приходить сообщения `InVelocity`.
6. Проверка ФБ 2: `home`, `ma 90`, `ma -360 200`, `ma 720`. Должно приходить сообщение `Done, s=...`.
   Если во время движения ввести `mv 100`, придёт `MC_MoveAbsolute: CommandAborted`.
7. Графики для отчёта: включите `mon 1` и откройте Serial Plotter Arduino IDE.
   На графике будут кривые s_set, s, v_set, v, u.
8. Настройка регулятора при необходимости: `set kv 0.02`, `set tn 0.05`, `set kpos 20`, `acc 3000`.

## 7. Команды консоли

```
on | off | reset | home [pos]
mv <°/с> | rpm <об/мин> | stop          — MC_MoveVelocity
ma <pos°> [v°/с]                         — MC_MoveAbsolute
acc <°/с²> | vel <°/с>
st | par | mon [0|1]
set kv|tn|ff|kpos|tf|vmax|amax|lag|win|motdir|encdir|ratio|ppr <значение>
cal | cal <N>
```
